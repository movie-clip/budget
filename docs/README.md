# HomeCharts Documentation

This folder contains the current documentation for the HomeCharts desktop application.

## Documents

- `PROJECT_GUIDE.md`
  - Product overview and feature usage guide.
  - Intended for daily app usage and feature understanding.

- `TECHNICAL_DESIGN.md`
  - Architecture, data model, use-case flow, and design constraints.
  - Intended for implementation and future feature work.

- `OPERATIONS.md`
  - Build/test/run, packaging, release checklist, and dependency policy.
  - Intended for maintainers and release operations.

- `RELEASE_NOTES.md`
  - Chronological release notes and notable shipped changes.

## Documentation Principles

1. Keep docs aligned with code in `src/` and `tests/`.
2. Prefer concrete behavior over historical migration notes.
3. Split user-facing usage and engineering design into separate docs.
4. Update docs in the same PR as behavior changes.
